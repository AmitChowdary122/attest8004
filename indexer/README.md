# indexer

Envio HyperIndex project for Attest8004 (SPEC §4.8). Generated and implemented in **P8**:
`config.yaml`, `schema.graphql` and the event handlers.

Planned entities: `Agent`, `ValidationRequest`, `ValidationResponse`, `Validator` (with derived
stats), `Mandate`, `InboxKey`, `PermissionEvent` and `AgentTrustSummary`.
